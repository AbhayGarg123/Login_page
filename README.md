# 🔐 Sign-In Page

A simple and responsive **Sign-In Page UI** built using HTML and CSS.

This project was created to practice frontend development concepts such as CSS Grid, form styling, responsive sizing, input fields, buttons, and layout design.

## 📸 Preview

The page contains:

- 🖼️ Washing machine illustration on the left
- 🔐 Sign-in form on the right
- 📧 Email input field
- 🔑 Password input field
- 🔗 Forgot Password link
- 🚀 Login button
- 📝 Register Now link

## 🛠️ Technologies Used

- HTML5
- CSS3

## ✨ Features

- Clean and modern login interface
- Two-column layout
- CSS flex based design
- Styled input fields
- Login button with hover effect
- Forgot Password link
- Register Now link
- Responsive sizing using modern CSS units
- No JavaScript used
